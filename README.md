# GEN-ZZ CLUB

Official website for GEN-ZZ CLUB — a customized clothing and T-shirt business serving customers across South India.

## Website

GEN-ZZ CLUB allows customers to:

- Browse products
- View product details
- Choose available colours and sizes
- Request custom T-shirt designs
- Send customization requests through WhatsApp
- Submit bulk-order enquiries through WhatsApp
- Contact GEN-ZZ CLUB through WhatsApp, email and Instagram

## Admin Dashboard

The website includes a protected owner dashboard.

The owner can:

- Log in securely
- Add products
- Edit products
- Delete products
- Change product prices
- Change product descriptions
- Set product availability
- Mark products as featured
- Add colour variants
- Add sizes
- Upload product images
- Upload colour-variant images

Admin URL:

`/admin`
